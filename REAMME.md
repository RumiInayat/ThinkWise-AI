# ThinkWise-AI

ThinkWise-AI is an intelligent assistant designed to help students with homework and academic work.  
Unlike traditional solvers, it doesn’t just provide ready-made answers — instead, it guides you to **think through problems** and discover solutions yourself.

---

## ✨ Features
- AI-powered homework assistance  
- Encourages critical thinking and problem-solving  
- Simple, interactive interface with Streamlit  

---

## 🔑 Setup Instructions

1. **Create an API Key**  
   Get your API key from [Groq Console](https://console.groq.com/keys).

2. **Configure Environment Variables**  
   Create a `.env` file in the project root and add your API key:  
   ```env
   API_KEY=your_api_key_here
